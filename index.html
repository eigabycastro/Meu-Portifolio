01 — Sobre

Tecnologia, lógica e resolução de problemas.

Sou a Gaby, estudante de Sistemas de Informação e técnica em Informática. Sempre gostei de entender como as coisas funcionam e, principalmente, de descobrir como a tecnologia pode transformar uma ideia em algo concreto.

Gosto de criar interfaces bonitas, mas também gosto de estar por trás delas: pensar na lógica, estruturar as informações, automatizar processos e descobrir por que alguma coisa não está funcionando. Para mim, desenvolver não é apenas escrever código, mas encontrar uma forma inteligente de transformar uma necessidade em uma solução.

Minha experiência acabou me levando para além do desenvolvimento de interfaces. Já trabalhei com sistemas internos, automação de processos, análise de dados e suporte em tecnologia, tendo contato com diferentes etapas de um projeto. Isso me fez perceber que gosto justamente dessa mistura entre tecnologia, criatividade e resolução de problemas.

No fim, é isso que mais gosto na tecnologia: pegar uma ideia que existe só na cabeça e transformá-la em algo que realmente funciona.

Sistema de Treinamento

Sistema desenvolvido para uso interno. Por envolver dados corporativos, o código e a demonstração não são públicos — abaixo está um resumo do escopo e das decisões técnicas.

Problema

Centralizar a operação de treinamentos técnicos, evitando que solicitações, agenda, materiais, clientes e avaliações fiquem espalhados em processos manuais.

Solução desenvolvida

Aplicação Flask com frontend em HTML, CSS e JavaScript puro, autenticação por sessão, integração com Supabase, Google Sheets/Apps Script e envio de e-mails por Resend ou SMTP.

Principais funcionalidades

  • Login, sessão, troca de senha e controle por perfil/departamento.
  • Dashboard, indicadores, solicitações, aprovação e recusa com motivo obrigatório.
  • Agenda semanal/mensal e registro de atividades internas.
  • Cadastro de clientes e máquinas associadas.
  • Biblioteca com upload, preview e download de materiais, incluindo arquivos ZIP.
  • Avaliações com anexos, links públicos por token e QR Code gerado no frontend.
  • Banco Supabase/PostgreSQL e fallback local em JSON.
Python Flask JavaScript Supabase PostgreSQL Google Apps Script Render Vercel

Sistema de Gestão Integrada XCMG

Aplicação web modular para apoiar registros e consultas de processos internos, descrita de forma segura e sem exposição de dados corporativos.

O que faz

Reúne módulos de registros financeiros, Lei do Bem, traduções técnicas e visualização de dados em uma interface Flask com formulários e endpoints JSON.

Integrações

Utiliza Google Sheets como armazenamento, Flask-Mail para e-mails, upload de PDF/imagens e página de dashboard Power BI.

Principais funcionalidades

  • Rotas Flask para financeiro, Lei do Bem, tradução, visualização e dashboard.
  • Registro de dados em planilhas por módulo.
  • Upload de arquivos em formatos permitidos.
  • API de dados com filtros e endpoint de detalhes por registro.
  • Cache simples para reduzir leituras repetidas.

Automação de Pagamentos

Automação em Python para organizar solicitações recebidas por e-mail, anexos e registros em planilha sem depender de lançamento manual repetitivo.

O que faz

Lê e-mails do Outlook, extrai dados estruturados com regex, salva PDFs, envia anexos ao Google Drive e registra novas solicitações no Google Sheets.

Cuidados de dados

Compara nota fiscal, fornecedor e valor normalizado para evitar registros duplicados. Também há script de alerta para vencimentos próximos.
